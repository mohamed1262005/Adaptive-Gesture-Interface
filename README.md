# Adaptive Gesture Interface (AGI) 👁️🖐️

An AI-powered system designed to control computer peripherals—like the mouse cursor and clicks—using eye-tracking, gaze estimation, and hand gestures. Built with **Python, OpenCV, and MediaPipe**, this project offers a hands-free, touchless user interface.

## 🚀 Features
* **Eye Tracking & Gaze Estimation:** Move the mouse cursor smoothly across the screen based on eye movement.
* **Hand Gesture Control:** Perform actions like clicking, scrolling, or triggering shortcuts using specific hand gestures.
* **Intelligent & Responsive:** Designed to assist individuals with mobility impairments or to provide a futuristic touchless interaction experience.

## 📂 Project Structure
* `control_eye/`: Modules handling eye tracking and cursor movement logic.
* `hand_controle/`: Modules dedicated to detecting hand gestures and mapping them to mouse events.
* `icons/`: UI elements and visual assets used in the application.

## 💻 Tech Stack
* **Language:** Python 3.x
* **Core Libraries:** OpenCV, MediaPipe, PyAutoGUI, NumPy
